# Framework guide

Use this guide to choose a narrative framework for a post. For owner-audience blog posts, the per-type framework lists in the post-type files supersede the topic tables of the general guide: choose from the list for the post's type first, and use the scoring below only to rank the frameworks on that list.

## Scoring

Start every candidate at zero and apply the modifiers in order.

1. Family affinity (0 to 3 points): primary family for the post's tone = 3, secondary family = 1, others = 0.
   - Educational: Foundational, then Rhetorical.
   - Provocative: Existential, then Absurdist.
   - Storytelling: Foundational, then Non-linear.
   - Technical: Non-linear, then Foundational.
   - Reflective or personal: Moral, then Foundational.
   - Provocative and prescriptive: Moral, then Rhetorical.
   - Educational and storytelling: Foundational, then Non-linear.
   - Provocative and storytelling: Existential, then Absurdist.
2. Length filter (pass or fail): eliminate frameworks above the complexity ceiling for the length. Short pieces (800 to 1,500 words) allow low complexity only, and exclude Story Circle in its full eight steps, Reverse Chronology, and the Jeremiad. Medium pieces (1,500 to 3,000) allow medium complexity. Long pieces (3,000 to 5,000) allow high complexity but exclude In Medias Res, whose impact fades at length.
3. Topic signal (+3 points): the framework appears in the post type's list for this kind of problem.
4. Readership (+1 or -1 point): owners read like leaders and managers, so favor Rhetorical and Foundational families (+1) and back claims with evidence. Moral frameworks need the writer to be a credible member of the community being addressed.
5. Tiebreaker: prefer lower complexity, then the order of the post type's list.

If the top score is 3 or less, the match is weak: say so in the plan and fall back to Three-Act Structure.

## Compatibility

- In Medias Res works as an opening for nearly any framework: start with the moment, then move into the chosen structure.
- Strong combinations: Petal with converging threads; Three-Act with the False Start (Act 1 is the false start, the break becomes the Act 1 to 2 boundary); the Socratic Path inside a layered explanation; the Montaigne with a single twist as the discovery moment.
- Combinations to avoid: Reverse Chronology with a twist structure (running backward removes the surprise); Kafkaesque Labyrinth with the Socratic Path (disorientation and clarity work against each other); the Dialectic with the False Start (the False Start frames the thesis as wrong, the Dialectic needs it genuinely strong); the Jeremiad with comic structures (moral weight and irreverence undercut each other); the Montaigne with the Sparkline (the deliberate oscillation shows through the exploratory surface).
- Combine at most two: a primary for the whole post and a secondary for one section. Check the "Combination Notes" in both framework files first.
