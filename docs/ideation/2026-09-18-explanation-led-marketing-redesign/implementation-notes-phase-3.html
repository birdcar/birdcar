Implementation Notes — Phase 3

Explanation-led marketing redesign · 2026-09-19 · Reading and print

Diagram motion — explicit opt-in

Context
The existing Walkthrough component always attached its animation hook. The spec requires reading figures to be static and marketing animation explicitly opted in.
Decision
Default the concrete animate prop to false and opt in at the single homepage invocation. This adds one small change to resources/views/pages/index.blade.php beyond the listed Phase 3 files, preserving the approved homepage behavior.
Alternative
Default animation on and opt articles out; that would make future reading uses move accidentally.

Caption grammar — quoted literal text

Context
The narrow example uses double quotes, while acceptance asks for captions containing quotes and markup.
Decision
Accept single-line captions with escaped double quotes and backslashes only. Blade escapes the decoded literal text. Retain each authored diagram’s existing caption after the supplied caption, so the reporting proof boundary cannot disappear.
Alternative
No attribute parser, Markdown captions, dynamic view paths, or raw SVG loader.

Review environment — available tools and source coverage

Context
The research subagent could not access MCP; task-list tools and a commit skill are not exposed. The existing archive contains inline code, but no fenced code blocks or Markdown tables.
Decision
Use Boost directly for version-scoped docs and the configured specimen URL. Track completion in acceptance.md. Use the real charts for table review and a temporary browser-only table/code stress probe rather than inserting demonstration content into the archive.
Alternative
Do not add dependencies, a public article, or a PDF-generation feature to satisfy review tooling.
