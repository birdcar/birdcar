Implementation Notes — Phase 2

Consistent Voice Publishing · 2026-10-12 · Voice and goals canon in every prompt

Pre-canon gate — pause, not fail

Context
The spec says an activity without input.canon "fails" with the restart message. A Failed activity shows Retry, and RetryEditorialActivity does not refreeze input, so Retry would fail the same way forever.
Decision
RunEditorialActivity::handle() throws the message (EditorialActivity::PRE_CANON_PAUSE_REASON) before the agent or conversation is built; handleFailure pauses it with that pause_reason. It is in neither RESUMABLE_PAUSE_REASONS nor CONFIGURATION_PAUSE_REASONS. The test asserts status Paused, the exact reason, no conversation and Http::assertNothingSent(). Restart: for interview, research, plan and draft a new start creates a new row because the canon changes prompt_hash. For review, reconciliation and recheck kinds idempotency ignores prompt_hash, so the owner needs a new review cycle or batch key; the dev database's one failed review_buyer row will hit this.
Alternative
Setting status Failed (literal spec reading); including the canon version in review idempotency keys (could duplicate auto-queued reviews after a deploy).

EditorialAgent — goals and rubric not repeated in the user message

Context
promptText() JSON-encodes the whole input, so the frozen rubric and goals would be sent twice (system and user message), about 15-20k extra tokens for the Drafter.
Decision
promptText() drops canon.rubric and canon.goals; the user message keeps version, hash, role, rubric_files, exemplars and exemplar_label. The system message renders goals and rubric only from the frozen input. The contract test asserts both halves.
Alternative
Sending the full input as before.

Canon block — hash key and rubric_files order

Context
The contract asks for a version id and a content hash; in Phase 2 they are the same manifest hash.
Decision
The frozen block carries both 'version' and 'hash' (equal) so Phase 8 can split them without changing the input shape. rubric_files is a path => sha256 map keyed by repo-relative paths; Postgres jsonb reorders its keys, so roles.json order lives in the rubric text, and tests compare the keys canonically.
Alternative
A single version key; a list of {path, hash} pairs.

VoiceCanon — logical manifest paths and config override

Context
"Paths relative to the repo root" conflicts with pointing the canon at a temporary copy in tests.
Decision
Added publishing_agents.canon.path and .archive_path. Manifest paths are always logical: resources/publishing/canon/<rel> and resources/writing/<slug>.md, so a byte-identical copy yields the same version. Only *.md and *.json are hashed and hidden files are skipped (.DS_Store never changes the version). CanonSnapshot gained an exemplarManifest constructor argument and frozenFor()/exemplarLabel() helpers so StartEditorialActivity, EditorialAgentsTest and the manual trial share one builder.
Alternative
base_path()-relative paths (a temp copy would hash differently).

Exemplars — directive blocks dropped whole

Context
The spec says to drop @figure, @aside and @callout blocks; it does not say whether their contents go too.
Decision
Whole blocks are dropped, contents included: the figures carry only captions, the epigraph in 'The tools that build the tools' is someone else's quotation, and the one callout in 'Your AI wrote a bug' is a takeaway summary. Titles come from the YAML frontmatter.
Alternative
Keeping callout prose (owner's voice, but a summary box the blog channel bans).

Site copy snapshot — straight quotes

Context
The approved homepage and Walkthrough copy uses curly apostrophes, which the canon's curly-quotes rule bans in manuscripts.
Decision
The snapshot keeps the approved wording (hero, "fifteen years", FAQ answers) but uses straight quotes so the Drafter does not imitate a banned character. Text was extracted from resources/views/pages/index.blade.php and walkthrough.blade.php.
Alternative
Byte-faithful curly quotes.

Canon decomposition — framework copies and authored files

Context
The 13 framework files are copied from new-post-skill; they contain no ~/.config or FW/ paths but do use em dashes and curly quotes. No role receives them yet (Phase 4).
Decision
Framework files are verbatim copies. Authored canon files avoid em dashes and name the Sisyphean Arc and Comedian's Set without paths. A test checks every *.md path a canon file mentions resolves inside the canon. The work-story template says "its old internal name" instead of repeating the excluded name.
Alternative
Rewriting the framework prose to the house style now.

Role instructions — output contracts kept

Context
The spec asks to shorten roleInstructions(); they were already one sentence each, and the reconciler/rechecker ones carry output contracts RunEditorialActivity enforces.
Decision
Planner, Drafter, VoiceReviewer and BuyerReviewer now defer to the rubric (BuyerReviewer reads the owner from the business goals). Reconciler and Rechecker instructions are unchanged, and their contracts are also restated in roles/reconciler.md and roles/rechecker.md.
Alternative
Cutting the contract wording.

Tests outside the spec

Context
EditorialAgentsTest built inputs with no canon, and the manual trial replays recorded inputs.
Decision
EditorialAgentsTest's helper merges CanonSnapshot::frozenFor(). The manual trial no longer seeds a published archive article; replays drop the obsolete voice_context and freeze the current canon. PublishingJourneyTest lost its archive seed and the now-unused journeyDocument() helper. EditorialOutput::VERSION is not bumped (the canon already changes prompt_hash).
Alternative
Letting replays refuse.

Owner follow-ups

Context
.ai/rules/actions.md says archive files are import/parity inputs only; .ai/rules/resources.md says PRODUCT.md owns written voice.
Decision
VoiceCanon (app/Services) reads resources/writing/*.md for agent exemplars, not for public pages, as the contract's fixed-exemplar decision requires. PRODUCT.md now points at the canon. Whether either rule should be updated is the owner's call; no record-rule was made.
Alternative
Copying the essays into the canon (would drift from the archive).
