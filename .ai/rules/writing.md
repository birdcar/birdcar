# Writing

## Preserve the original essay format
The imported essay files include Birdcar Markdown directives (@figure, @aside, @callout), not just standard Markdown. Preserve those source files and render the directives in ReadWriting; keep note titles, captions, chart values, and the original author mention destinations when changing presentation. A byte-identical import alone does not verify correct article rendering.
